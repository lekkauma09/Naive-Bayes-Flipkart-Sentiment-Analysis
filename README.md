# 💬 Flipkart Sentiment Analysis

> **Turning customer opinions into useful insights. 🛍️🧠**

A Natural Language Processing project that analyzes **Flipkart product reviews** and classifies customer sentiment into different categories.

---

## 🧠 What's the Project About?

Online reviews contain valuable information about how customers feel about a product.

This project uses **Natural Language Processing (NLP)** and the **Naïve Bayes algorithm** to analyze customer reviews and classify their sentiment.

```text
Customer Review
      ↓
Text Preprocessing
      ↓
Feature Extraction
      ↓
Naïve Bayes Model
      ↓
Sentiment Prediction
```

---

## 💭 Sentiment Categories

The project works with sentiment categories such as:

* 🟢 **Positive**
* 🔴 **Negative**
* 🟡 **Neutral**

This makes it easier to understand large amounts of customer feedback.

## 🚀 Run Locally

### Clone the repository

```bash
git clone https://github.com/lekkauma09/Naive-Bayes-Flipkart-Sentiment-Analysis.git
```

### Enter the folder

```bash
cd Naive-Bayes-Flipkart-Sentiment-Analysis
```

### Install required libraries

```bash
pip install pandas numpy scikit-learn jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Run the notebook cells to train the model and generate predictions.
